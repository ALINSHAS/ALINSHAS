A web-based recruitment platform designed to connect **job seekers and companies** through job posting, profile management, job discovery, skill-based matching and application management.

> **Note:** The implemented matching system uses application logic and matching criteria. It does **not** use Machine Learning or NLP models.

### 🧰 Technology Stack

```text
Backend     → Python · Flask
Frontend    → HTML · CSS · Bootstrap · JavaScript
Database    → MySQL · SQL
```

### ✨ Key Features

- 👤 Job seeker registration
- 🏢 Company registration
- 📄 Profile management
- 📢 Job posting
- 🔍 Job search and filtering
- 🎯 Skill and requirement-based matching
- 📑 Resume management
